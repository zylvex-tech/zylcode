# ZylCode Navigation Guide

## Current View: Provider Settings
You're currently seeing the **Provider Settings — Fallback Chain** page. This is where you configure AI model providers.

## How to Switch to Main IDE View

### Option 1: Use Keyboard Shortcuts
- **Ctrl+1**: Stream & Tool Panel (main IDE)
- **Ctrl+2**: Provider Settings (current view)
- **Ctrl+3**: MCP Activity
- **Ctrl+4**: Live Feed

### Option 2: Click Navigation Tabs
Look for navigation tabs at the top or side of the application. The main IDE view should have:
- **Stream & Tool Panel** - Enter prompts and generate content
- **MCP Activity** - View registered tools
- **Live Feed** - Monitor tool calls

### Option 3: Use the Menu Bar
Look for a menu bar at the top of the application with options like:
- **View** → **Panels** → **Stream & Tool Panel**
- **Tools** → **MCP Activity**
- **Help** → **About**

## What You Should See in Main IDE View

### Stream & Tool Panel
- **Model Override**: Optional field to specify AI model
- **Prompt Area**: Large text area to describe what you want to build
- **Generate Button**: Click to run the AI
- **Verify Button**: Click to verify the output

### MCP Activity
- **30 Tools Registered**: Your MCP tools configuration is loaded
- **Tool Categories**: Development, DevOps, Database, AI/ML, etc.
- **Live Updates**: Tools are hot-reloadable

### Live Feed
- **Tool Calls**: See when tools are executed
- **Results**: View tool execution results
- **Errors**: Monitor any tool failures

## Testing the Application

### Step 1: Enter a Prompt
In the **Stream & Tool Panel**, type something like:
```
Create a simple Rust function that calculates the factorial of a number
```

### Step 2: Click Generate
The AI will process your prompt and generate code.

### Step 3: View Results
- **Artifacts Panel**: Shows generated files
- **Live Feed**: Shows tool calls and execution
- **Provider Settings**: Shows which AI model was used

## Troubleshooting

### If you can't find the main IDE view
1. **Look for tabs** at the top of the application
2. **Try keyboard shortcuts** (Ctrl+1, Ctrl+2, etc.)
3. **Check the menu bar** for View options
4. **Restart the application** if needed

### If the application is still showing provider settings
1. **Click outside** the provider settings panel
2. **Press Escape** to close the provider settings
3. **Look for a "Back" or "Close" button**
4. **Try resizing the window** to see if other panels are hidden

## Next Steps

Once you're in the main IDE view:
1. **Explore the 30 MCP tools** in the MCP Activity panel
2. **Try generating code** with different prompts
3. **Test tool execution** by asking the AI to use specific tools
4. **Customize the interface** by rearranging panels

## Need Help?

If you're still having trouble navigating the application:
1. **Check the title bar** - It should show "ZylCode" not "Provider Settings"
2. **Look for a home button** - Usually in the top-left corner
3. **Try the Help menu** - Look for documentation or tutorials
4. **Restart the application** - Sometimes a fresh start helps

**Remember**: The application is working correctly! You just need to navigate to the main IDE view to see the full interface.
