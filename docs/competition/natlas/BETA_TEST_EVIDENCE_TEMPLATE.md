## How to record a test

1. A tester is a **real person** who has consented to being named. Use their name or an agreed
   identifier.
2. The tester attempts **one bounded developer task** on **one named repository**.
3. The N-ATLAS invocation evidence for that attempt is preserved using the non-secret fields only
   (`NatlasEvidence`: timestamp, provider, model, request id, classification, status, latency,
   success, redacted error). **Never record an API key or secret.**
4. Record the outcome **as observed** — including partial success and failure. A failed task that is
   reported honestly is worth more than a success that is not.
5. Time is **measured**, not estimated.
6. Feedback is recorded **verbatim**, not summarised into something more flattering.
7. An issue is recorded with its resolution, or explicitly left unresolved.
