Phase 13 · Delivery Engine — where the CLI gap lives

Roadmap deliverables: Git · PRs · CI/CD · Windows installers · macOS bundles · Linux packages · Docker · release evidence bundles.

The v0.2.2 release ships the desktop app only. zylcode and zylcode-core-cli are built by the workspace but never packaged, because this phase has not started.

Hard rule from the roadmap: the Delivery Engine cannot publish an artifact whose required proofs are below threshold — so the current hand-wired release.yml is a stopgap, not Phase 13.
