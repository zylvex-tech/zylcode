== 5. The user workflow under test ==
   apps/zylcode-desktop/src/features/design/DesignStudio.test.tsx drives the real component:
   - create a project by name, then add a text element and edit it
   - save (revision advances, UNSAVED clears)
   - unmount the component and mount a fresh one against the same store, reopen the
     project, and assert the saved text is present (the restart path)
   - undo/redo, one-drag-one-undo, validation refusal, failed save reported as failure
   - unsaved-changes guard on project switch
   - export HTML containing the current text
